# 🎯 التحديثات الجديدة للكاشير

## ✨ الميزات الجديدة المضافة

### 1️⃣ الخصم على الفاتورة (Discount Feature)
**التحديث:** إضافة خاصية الخصم على الفاتورة مع حساب تلقائي

#### المميزات:
- ✅ إدخال **نسبة خصم** (%)
- ✅ حساب **المبلغ المخصوم** تلقائياً
- ✅ عرض **المجموع الفرعي** قبل الخصم
- ✅ عرض **الإجمالي النهائي** بعد الخصم
- ✅ الخصم يظهر في **الفاتورة المطبوعة**

#### الواجهة:
```
┌─────────────────────────────────┐
│ نسبة الخصم (%)    │ المبلغ المخصوم  │
│     [0]%        │   0 ج.م        │
└─────────────────────────────────┘
```

#### الحساب:
```
المجموع الفرعي = إجمالي الأصناف
المبلغ المخصوم = المجموع الفرعي × (نسبة الخصم / 100)
الإجمالي النهائي = المجموع الفرعي - المبلغ المخصوم
```

---

### 2️⃣ تقفيل الحساب من داخل Modal الفاتورة
**التحديث:** نقل زر "تقفيل الحساب" إلى داخل نافذة الفاتورة

#### المميزات:
- ✅ زر **تقفيل الحساب** مباشرة في الفاتورة
- ✅ لا حاجة للخروج من النافذة والعودة
- ✅ يتم تقفيل جميع الطلبات دفعة واحدة
- ✅ الطاولة تعود إلى حالة **"فارغة"** تلقائياً

#### الأزرار في Modal:
```
┌──────────┬──────────┬──────────┬──────────┐
│ طباعة   │ نسخ     │ تقفيل   │ إغلاق   │
│ (أزرق)   │ (أخضر)   │ (أحمر)   │ (رمادي) │
└──────────┴──────────┴──────────┴──────────┘
```

---

### 3️⃣ فتح طاولة جديدة من الكاشير
**التحديث:** إضافة إمكانية فتح طاولة جديدة مباشرة من قسم الكاشير

#### المميزات:
- ✅ إدخال **رقم الطاولة** الجديدة (1-20)
- ✅ إدخال **اسم العميل** (اختياري)
- ✅ التحقق من **عدم استخدام الطاولة** مسبقاً
- ✅ إنشاء **طلب جديد** فارغ تلقائياً
- ✅ تحديث شبكة الطاولات فوراً

#### الواجهة:
```
┌─────────────────────────────────┬──────────┐
│ اسم العميل (اختياري)  │ فتح طاولة│
│ [_________________]  │  (أخضر) │
└─────────────────────────────────┴──────────┘
```

#### الخطوات:
1. أدخل اسم العميل (أو اتركه لـ "عميل جديد")
2. أدخل رقم الطاولة الجديد
3. اضغط "فتح طاولة"
4. ستظهر الطاولة في شبكة الطاولات

## 🔧 التعديلات التقنية

### تحديثات HTML:

1. **قسم الخصم الجديد:**
   ```html
   <div class="bg-gradient-to-r from-purple-50 to-purple-100 p-5 rounded-lg">
       <input id="billDiscount" type="number" placeholder="0" min="0" max="100" step="0.5">
       <p id="billDiscountAmount">المبلغ المخصوم</p>
   </div>
   ```

2. **قسم الإجمالي المحدث:**
   ```html
   <div id="billSubtotal">المجموع الفرعي</div>
   <div id="billTotal">الإجمالي النهائي</div>
   ```

3. **أزرار Modal محدثة:**
   - أضيف زر **تقفيل** (أحمر)
   - تقليل حجم الأزرار لـ 4 أزرار بدلاً من 3

4. **قسم العمليات الجديد:**
   - صف أول: عرض فاتورة
   - صف ثاني: **فتح طاولة جديدة**

### تحديثات JavaScript:

1. **دالة updateBillTotal()** - جديدة
   ```javascript
   - حساب الخصم تلقائياً
   - تحديث عرض المبالغ
   - حفظ الإجمالي النهائي
   ```

2. **دالة setTableNumberAndOpenBill()** - محدثة
   ```javascript
   - إضافة معالجة الخصم
   - حفظ البيانات للخصم
   - استدعاء updateBillTotal()
   ```

3. **دالة closeTableAccount()** - محدثة
   ```javascript
   - استخدام currentBillTableNum من Modal
   - إعادة تعيين الخصم بعد التقفيل
   - تحديث البيانات فوراً
   ```

4. **دالة openNewTable()** - جديدة
   ```javascript
   - التحقق من صحة رقم الطاولة
   - التحقق من عدم استخدام الطاولة
   - إنشاء طلب جديد فارغ
   - تحديث شبكة الطاولات
   ```

5. **دالة printTableBill()** - محدثة
   ```javascript
   - قراءة قيمة الخصم
   - حساب المبالغ مع الخصم
   - عرض الخصم في الفاتورة المطبوعة
   - عرض المجموع الفرعي والنهائي
   ```

## ✅ الفوائد الرئيسية

1. **سهولة تطبيق الخصومات**

   - يظهر في الفاتورة المطبوعة

   - فتح طاولات جديدة بسهولة

   - تحديث فوري
